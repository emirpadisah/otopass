# Security Policy

## Reporting a vulnerability

Do not disclose security vulnerabilities in public issues. Send the affected URL, reproduction steps, impact, and any supporting evidence to `info@otokopru.com`.

Secrets, personal data, access tokens, passwords, and customer vehicle records must not be included in public reports. We will acknowledge actionable reports and coordinate remediation before disclosure.

## Supported version

Only the current production deployment from the `master` branch receives security fixes.
